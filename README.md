# Jeremiah Pantaras - Portfolio Website

A modern, responsive portfolio website showcasing my professional journey as a Junior Software Engineer and Full-Stack Developer.

## 🚀 Features

- **Responsive Design** - Fully responsive layout that works seamlessly across all devices
- **Dark/Light Mode** - Toggle between dark and light themes with smooth transitions
- **Interactive UI** - Modern card-based layout with hover effects and animations
- **Floating Particles** - Animated particle effects on profile avatar
- **Verified Badge** - Professional verification badge on profile name
- **Company Section** - Highlighting my role as Founder & CEO of COS Devs
- **Project Showcase** - Detailed project cards with technology tags
- **Experience Timeline** - Visual timeline of professional experience
- **Tech Stack Display** - Categorized showcase of technologies and tools
- **Certifications** - Display of awards and certifications
- **Footer Section** - Contact information and quick links

## 🛠️ Technologies Used

### Frontend
- **React 19.1.1** - UI library
- **Vite 7.1.7** - Build tool and dev server
- **Tailwind CSS 4.1.16** - Utility-first CSS framework
- **Lucide React** - Icon library

### Additional Libraries
- **React Router DOM** - Client-side routing
- **Vercel Analytics** - Analytics integration
- **React Icons** - Additional icon set

### Development Tools
- **ESLint** - Code linting
- **PostCSS** - CSS processing
